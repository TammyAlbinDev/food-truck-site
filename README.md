# food-truck-site

## What changes at each breakpoint

- Phones: Menu cards display in 1 column, Visit us boxes stack vertically, and the heading is 2.5rem.
- Tablets (768px and up): Menu cards display in 2 columns, Visit us boxes appear side by side, and the heading increases to 4.5rem.
- Computers (992px and up): Menu cards display in 3 columns, with extra horizontal padding.
